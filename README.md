# flayer-maker

Generador de flyers de servicios en una sola página web: llena el formulario, ajusta los colores y obtén un flyer listo para compartir, sin instalar nada y sin pasos de compilación.

## Qué hace

- **Editor por secciones**: marca, título e introducción, producto o servicio estrella, lista de servicios o productos y bloques de texto libres que puedes agregar y quitar.
- **Vista previa en vivo**: cada cambio en el formulario se refleja al instante en el flyer.
- **Colores personalizables**: elige el color principal y los acentos con selector de color o código hexadecimal.
- **Salida lista para usar**: descarga el flyer como HTML, cópialo al portapapeles o imprímelo / guárdalo en PDF desde el navegador.
- **100% local**: todo corre en el navegador; no envía datos a ningún servidor.

## Cómo usarlo

1. Abre `index.html` en tu navegador (o sirve la carpeta con cualquier servidor estático, por ejemplo `python3 -m http.server`).
2. Completa los datos de tu servicio en el panel de la izquierda.
3. Ajusta colores y bloques hasta que la vista previa te convenza.
4. Descarga, copia o imprime el flyer resultante.
